##Caso de Estudio: Sistema de gestión de almacén e inventario

Logistock es un sistema orientado a la gestión y el control de inventarios, cuyo propósito es facilitar la administración de productos y apoyar las actividades relacionadas con su preparación, recolección y control. El sistema contempla diferentes roles de usuario, entre ellos el Preparador, encargado de recolectar los productos solicitados, y el Supervisor, responsable de controlar las operaciones y autorizar los ajustes de inventario cuando sea necesario.

El repositorio contiene los diagramas elaborados durante el análisis y modelado del caso de estudio Logistock.
- Diagrama de casos de uso: representa los actores del sistema, sus funcionalidades principales y las relaciones entre ellos.
- Diagrama de secuencia: representa el orden temporal de las interacciones entre los actores y el sistema durante un proceso.
- Diagrama de comunicación: representa los objetos o participantes que intervienen en un proceso y los mensajes que intercambian.

El respositorio contiene un archivo README, carpetas correspondientes a cada Trabajo Práctico Experimental y dentro de cada carpeta los respectivos diagramas.
